## Abstract

A formula-by-formula trace of how a protocol becomes a QDOT value — the injury probability, the gain, and the aggregation from each runner to the leaderboard — each step anchored in the simulator's source code at a named commit. It includes an absence register: what each step provably does not touch, the claims that reading falsified, and the results of the automated check that guards those absences.

It is the evidence that the formal specification describes the code that actually runs.
