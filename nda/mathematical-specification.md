## Abstract

The complete mathematical system of the simulator and the QDOT metric as one self-contained reference, in the order of the computation: protocol input and session generation, the compliance model, training dose, fitness–fatigue dynamics, the mapping from performance to VDOT gain, the injury model, Monte Carlo population sampling and the QDOT aggregation. It ends with the full parameter table, one name per parameter, the external validation and the specification's own scope and limitations.

Both white papers in this repository describe this system without its equations or values; this is where they are.
